# Dataset Sanity

Профилировщик CSV перед анализом или обучением модели: находит пустые ячейки, дубликаты строк и смешение чисел с текстом. Создаёт JSON или автономный HTML-отчёт.

**Python 3.9+ · Стандартная библиотека · Отчёт открывается без интернета**

## Быстрый запуск

Из корневой папки проекта:

```bash
python3 sanity.py examples/support-tickets.csv
python3 sanity.py examples/support-tickets.csv --format html --output report.html
python3 sanity.py examples/support-tickets.csv --fail-on-issues
```

Открой `report.html` в браузере. В демонстрационном наборе **10 строк, 5 столбцов, 2 пропуска и 1 повторная строка**. Время ответа содержит строку `unknown`, поэтому тип столбца — `mixed`. Третий запуск возвращает **1**, поскольку в примере намеренно есть проблемы.

Готовый пример: [examples/report.html](examples/report.html). Все строки демонстрационного CSV вымышлены; реальные персональные данные не используются.

Для разделителя `;`:

```bash
python3 sanity.py your-data.csv --delimiter ";" --output report.json
```

На Windows используй `python`, если команда `python3` недоступна. Установка пакетов не требуется.

## Что попадает в отчёт

| Метрика | Как считается |
|---|---|
| Missing | Пустые строки после удаления пробелов по краям |
| Duplicate rows | Число строк сверх первого экземпляра, сравниваются все столбцы |
| Unique | Число различных непустых значений |
| Type | `empty`, `numeric`, `mixed` или `text` |
| Numeric range | Минимум и максимум, только для полностью числовых столбцов |
| Top values | До пяти самых частых непустых значений и частота |

`NaN`, `Infinity`, `NA` и `null` не считаются пропусками автоматически. `NaN` и бесконечности также не считаются конечными числами. Числа читаются через `Decimal`; числовые границы выводятся строками, чтобы очень большие значения не превратились в невалидный JSON.

## Устройство

```text
CSV → validate header and row lengths → normalize cells
    → column statistics + duplicate detection → JSON / HTML
```

`profile()` отделена от представления и может вызываться из другого Python-скрипта. `html_report()` экранирует значения входных данных. CLI обрабатывает пути, разделитель, выбор формата и коды завершения.

Пустой файл, повторяющиеся названия столбцов и неправильная длина строки отклоняются с ошибкой. CSV с одним заголовком допустим и получает предупреждение `No data rows`. Поддерживаются UTF-8 с BOM и многострочные поля в кавычках.

## Проверка и коды завершения

```bash
python3 -m unittest discover -s tests -v
```

Тесты проверяют демонстрационные метрики, пропуски, дубликаты, BOM и разделитель, некорректный CSV, многострочные поля, большие числа и экранирование HTML.

- `0`: отчёт построен; предупреждения сами по себе не являются ошибкой команды.
- `1`: указан `--fail-on-issues` и найдены предупреждения.
- `2`: ошибка аргументов, файла или структуры CSV.

## Ограничения

Данные загружаются в память. Инструмент рассчитан на небольшие файлы, а не многогигабайтные датасеты. Типы определяются эвристически: ID `001` выглядит как число, даты отдельно не распознаются. Дубликаты и константные столбцы требуют проверки человеком и не всегда являются ошибкой. Автоматического удаления или исправления данных нет.

HTML содержит примеры значений исходного файла — учитывай это при передаче отчёта другим людям.
